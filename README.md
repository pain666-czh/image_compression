# 图片压缩工具

纯浏览器端的图片压缩 Web 工具：上传图片，选择目标文件大小上限（如 64KB）与证件照标准尺寸（一寸 / 大一寸 / 二寸等），一键压缩并下载。**全部处理在本地完成，图片不会上传任何服务器。**

## 功能特性

- **多种上传方式**：点击选择、拖拽、Ctrl + V 粘贴；支持 JPG / PNG / WebP / BMP
- **压缩极限**：预设 30K / 50K / 64K / 100K / 200K / 500K / 1M 档位，支持自定义 KB
- **证件照规格**：小一寸 / 一寸 / 大一寸 / 二寸（300 DPI），支持自定义宽 × 高
- **前后对比**：压缩前后像素、文件大小、压缩率一目了然
- **一键下载**：自动生成语义化文件名，如 `photo_一寸_64KB.jpg`

## 使用方式

无需安装、无需构建：

- **本地使用**：双击 `index.html` 在浏览器中打开即可
- **在线部署**：目录整体托管到任意静态服务（GitHub Pages / Vercel / Nginx 等）即可

推荐使用最新版 Chrome / Edge / Firefox / Safari。

## 技术实现

- **技术栈**：HTML + CSS + 原生 JavaScript + Canvas API，零依赖、零后端
- **压缩算法**：`canvas.toBlob` 按 JPEG quality 二分搜索（约 8 轮收敛），在大小上限内取得最高画质
- **兜底策略**：质量压到下限仍超限时，逐轮按 10% 缩小输出尺寸重新逼近
- **画质保障**：大图分级降采样避免锯齿；cover 模式居中裁剪不变形；透明图自动铺白底
- **细节处理**：EXIF 方向自动校正、GIF 取首帧、超大图预缩放
